Сервис прогнозирования доходов клиентов на основе ML-модели (Ансамбль CatBoost + LightGBM). Разработан командой **"Титаник 2"** для хакатона Альфа-Банка 2025.

Сервис позволяет не только искать существующих клиентов, но и моделировать доход "на лету" для новых профилей, используя более 200 поведенческих и финансовых факторов.

## 🚀 Ключевые возможности

### 1. Умный поиск клиентов
- **Мгновенный поиск** по базе из 70,000+ клиентов.
- **Автодополнение (Autocomplete):** Подсказки при вводе ID с предпросмотром прогноза.
- **Полный профиль:** Отображение прогнозируемого дохода, графика влияния факторов (SHAP) и персональных рекомендаций.

### 2. Интерактивный ML-Калькулятор
- **Real-time Inference:** Прогноз пересчитывается мгновенно при изменении любого параметра.
- **200+ Параметров:** Доступ ко всем признакам модели (транзакции, кредитная история, соцдем).
- **Умные значения по умолчанию:** Форма предзаполняется средними значениями по базе, чтобы не вводить всё вручную.
- **Визуализация:** График SHAP показывает, *почему* модель дала такой прогноз (какие факторы повысили или понизили доход).

### 3. Персонализация
- Автоматическая генерация банковских предложений (карты, кредиты, инвестиции) на основе прогноза и топ-факторов влияния.

## 🤖 Описание ML-модели

🏆 Текущий результат точности (Public Leaderboard): ~4.7M Weighted MAE

Валидация (10-Fold CV): Стабильная метрика с минимальным разбросом.

🧠 Краткое описание решения
Решение основано на ансамблировании (Blending) градиентных бустингов CatBoost и LightGBM. Ключевым фактором успеха стал глубокий Feature Engineering, направленный на выявление скрытых финансовых паттернов и несоответствий в данных, а также систематический подбор гиперпараметров с помощью Optuna.

Ключевые особенности подхода:
Сравнение источников данных (Data Mismatch): Выявлено, что разница между "Зарплатой в профиле" (Digital Profile) и "Расчетной зарплатой по банку" является мощнейшим предиктором (топ-1 по важности).

Финансовые потоки (Cash Flow): Использование разницы между приходом (Credit) и расходом (Debit) как прокси для накоплений.

Логарифмирование: Применение log1p для финансовых метрик с "тяжелыми хвостами" (High Variance features) для помощи моделям.

Оптимизация (Optuna): Тонкая настройка гиперпараметров CatBoost и LightGBM для минимизации Weighted MAE.

Ансамбль: Смешивание предсказаний CatBoost (60%) и LightGBM (40%) для снижения дисперсии ошибки.

## ⚡️ Быстрый старт

### 1. Предварительные требования
- **Node.js 18+**
- **Python 3.10+**
- *(Только для macOS)* Библиотека `libomp` для LightGBM:
  ```bash
  brew install libomp
  ```

### 2. Установка и запуск

#### Шаг 1: Запуск Backend (Сервер + ML)
Откройте терминал в корне проекта. Скрипт сам создаст виртуальное окружение, установит библиотеки и запустит сервер.

```bash
./run_backend.sh
```
*Сервер запустится на [http://localhost:8000](http://localhost:8000)*

#### Шаг 2: Запуск Frontend (Интерфейс)
Откройте **второй** терминал:

```bash
cd frontend
npm install
npm run dev
```
*Сайт откроется на [http://localhost:5173](http://localhost:5173)*

## 🧠 Переобучение модели

Если у вас появились новые данные (файлы `hackathon_income_train.csv` и `hackathon_income_test.csv` в папке `ml/data/raw/`), вы можете полностью переобучить пайплайн одной командой:

```bash
# Запуск полного цикла (ETL -> Train -> SHAP -> Recs -> Server)
./run_backend.sh -r 
#или
./run_backend.sh --retrain
#также есть возможность переобучения модели без запуска сервера
./run_backend.sh --retrain-only
```
